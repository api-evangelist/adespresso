## API status

- **No public API.** AdEspresso publishes no developer portal, no API reference, no OpenAPI /
  AsyncAPI / GraphQL SDL / Postman collection, and no MCP server or A2A agent card.
- **An API is claimed but gated.** The public pricing page lists "API access" as an
  **Enterprise-tier feature** ($259/month and up). No base URL, authentication model, scope
  list or contract is published anywhere on the public estate; the entitlement is named on the
  pricing page and nowhere else.
- **Do not confuse with Hootsuite.** The parent company runs a separate developer program at
  developer.hootsuite.com. That is Hootsuite's API, not AdEspresso's, and is profiled
  separately in this catalog.
- **Do not confuse with the Meta Marketing API.** AdEspresso is built on top of Facebook's
  Marketing API; it consumes that contract rather than exposing one.

## Open source

AdEspresso's GitHub org ([github.com/adespresso](https://github.com/adespresso)) has 25 public
repositories. Eight first-party PHP/Symfony packages are published on Packagist — two internal
Symfony bundles (feature flagging, white-labelling) and six OAuth client providers for OTHER
vendors' APIs (Mailchimp, HubSpot, Intercom, Infusionsoft, GetResponse, AWeber). **None is a
client for an AdEspresso API.** The remaining repos are forks of third-party libraries.
Newest first-party release: 2019-09-06. The open-source surface has been dormant for six years.
